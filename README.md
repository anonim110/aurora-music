# Aurora — музыкальный плеер

Десктопный музыкальный плеер с поиском, подборками и личной коллекцией.

## Возможности

- Поиск по названию и исполнителю, популярные треки по жанрам.
- Фильтр текущего списка и сортировка.
- Очередь: добавление кнопкой **+**, удаление кнопкой **−**, воспроизведение всей подборки.
- Избранное и история последних 100 уникальных прослушанных треков.
- Пауза, перемотка, громкость, перемешивание и повтор трека или очереди.
- При отключении звука сохраняется предыдущая громкость.
- Громкость, избранное, история, повтор и перемешивание сохраняются между запусками.
- При сворачивании или закрытии главного окна в правом нижнем углу рабочего стола появляется
  мини-плеер с названием песни, обложкой, прогрессом и кнопками паузы, остановки,
  переключения и возврата в главное окно. Музыка продолжает играть до паузы
  или остановки. Полный выход — кнопка выхода в мини-плеере или системном трее.

Очередь создаётся на текущий сеанс. Нажатие на трек в каталоге, поиске,
избранном или истории заменяет очередь текущим отфильтрованным списком.
Кнопка **+** добавляет трек в существующую очередь. Удаление текущего трека
из очереди не прерывает его: следующим включается оставшийся следующий трек.

## Запуск

Требуется Python 3.10+ и Microsoft Edge WebView2 Runtime на Windows.

```powershell
python -m pip install -r requirements.txt
python aurora_music.py
```

Либо запустите `run.bat`. Он установит зависимости перед запуском.

## Установка Windows

Запустите `AuroraMusic-Setup-1.0.0.exe` из папки `dist` и пройдите мастер установки.
Он установит приложение для текущего пользователя, создаст ярлыки в меню «Пуск»
и на рабочем столе. Python для установленной версии не нужен. Для интерфейса
требуется Microsoft Edge WebView2 Runtime.

Сборка установщика из исходников на Windows:

```powershell
powershell -ExecutionPolicy Bypass -File packaging/build.ps1
```

Скрипт создаёт локальное окружение сборки, генерирует иконку, собирает
`dist/AuroraMusic/AuroraMusic.exe` через PyInstaller и затем создаёт установщик
через Inno Setup 7. Если Inno Setup установлен в другом месте, передайте путь
к компилятору параметром `-InnoCompiler`.

## Управление

| Клавиши | Действие |
| --- | --- |
| Пробел | Пауза / продолжить, когда фокус вне элементов управления |
| Ctrl+F | Перейти в строку поиска |
| Enter в поиске | Найти треки |
| Alt+→ / Alt+← | Следующий / предыдущий трек |
| Tab / Enter | Навигация и активация кнопок |

## Данные и загрузка

При запуске из исходников пользовательские данные записываются в
`aurora_data.json` рядом с приложением. Установленная версия хранит их в
`%LOCALAPPDATA%\AuroraMusic\aurora_data.json`, поэтому обновление приложения
не стирает настройки.
Запись выполняется через временный файл и атомарную замену. Для сохранения
настроек папка данных пользователя должна быть доступна для записи.
Аудио кэшируется в `%TEMP%\aurora_music\audio`.
Повторное воспроизведение кэшированного трека не требует новой загрузки.
Каждый запрос использует отдельную временную папку: быстрое переключение треков
не смешивает загрузки. ffmpeg поставляется с `imageio-ffmpeg`.

Если поиск временно недоступен, приложение покажет ошибку с возможностью
повторить запрос.

## Проверки

Из корня проекта, после установки зависимостей:

```powershell
python -m unittest discover -s tests -v
python -m tests.audio_smoke
python -m tests.desktop_smoke
```

`audio_smoke` создаёт локальный MP3 и проверяет настоящий микшер через тестовое
аудиоустройство, без вывода звука в колонки. `desktop_smoke` кратко открывает
настоящее окно WebView2 и проверяет связь с Python, мини-плеер и восстановление.
Обе проверки используют временные данные и не меняют вашу библиотеку.

Для проверки интерфейса необходимы Node.js, Playwright и установленный Edge:

```powershell
npm install --no-save playwright
node tests/ui.test.cjs
```

Интерфейс проверяется на локальных тестовых треках без сетевого доступа.
Отдельная проверка мини-плеера: `node tests/widget.test.cjs`.
